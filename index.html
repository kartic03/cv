Interpretable variant effect prediction

Building a variant effect predictor on ESM protein language models, using sparse autoencoder features from ESMC so a call arrives with a reason attached. When the model flags a mutation I want to name the learned feature that drove it, not return a damaging-or-benign score.

The accuracy target was fixed before I touched held-out data. A modest honest number is worth more than a tuned one.

Approach

I write my own pipelines and handle the statistics properly, and I have learned to distrust any number I have not traced back to the raw file. A good part of research computing is catching your own mistakes before a reviewer does.

That shows up in what I choose to report. In the toxicology benchmark it meant auditing for leakage before anything else and putting calibration and applicability domain next to accuracy, because a leaked split makes almost any architecture look competent. In the EEG work it meant preregistering the analysis and using equivalence testing, so that "no difference" was a claim I could defend rather than a failure to detect one.

What I want next is a role where the two channels stay merged. A protein model nobody ever tests in cells is just a spreadsheet, and I have seen enough screening campaigns run on intuition alone. I would rather keep doing both.
